# Lycian Way Hiking Blog

An interactive map-based blog application for the Lycian Way hiking trail, allowing users to explore the route and share their hiking experiences with images and text descriptions.

## Features

- Interactive map showing the Lycian Way hiking route
- Clickable markers displaying images and text descriptions
- Form to upload hiking experiences with geotagged locations
- Responsive design for mobile and desktop viewing
- Hosted on GitHub Pages for easy access

## Technologies Used

- HTML5
- CSS3
- JavaScript
- [Leaflet.js](https://leafletjs.com/) for interactive maps
- OpenStreetMap for base map tiles

## Setup Instructions

1. Clone or download this repository
2. Open `index.html` in a web browser to view the application locally
3. To make changes, edit the HTML, CSS, or JavaScript files as needed

## Deployment to GitHub Pages

1. Create a new repository on GitHub or use an existing one
2. Push this code to the repository
3. In your repository settings, go to "Pages"
4. Select source as "Deploy from a branch"
5. Choose the main branch and save
6. Your site will be available at `https://yourusername.github.io/repository-name`

## How to Use

### Adding Content

1. Scroll down to the "Share Your Experience" section
2. Fill in the form with:
   - Title for your post
   - Description of your experience
   - Upload an image (optional)
   - Latitude and longitude coordinates for the location
3. Click "Add to Map" to place your marker on the map

### Viewing Content

- Click on any marker on the map to see the associated content
- The content will also appear in the content display area below the map

## Customization

The application can be customized by modifying:

- `styles.css` for visual styling
- `app.js` for map behavior and functionality
- `index.html` for layout and content structure

## About the Lycian Way

The Lycian Way is a long-distance walking route in Turkey, stretching approximately 540 km (340 mi) along the Mediterranean coast from Fethiye to Antalya. It passes through ancient Lycian sites, pine forests, and beautiful coastal scenery.
